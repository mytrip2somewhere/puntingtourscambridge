夏季我大半的乘客都是家庭出行的游客,他们登船前在河边总会问我同一个问题:孩子坐这个安全吗?这是个合理的问题。自2021年起我就在康河上带领[撑篙行程](/zh/tours/),所以这里是诚实、实用的答案,包括那些没人会告诉你、直到你已经抱着一个扭来扭去的小孩站在低矮船边的细节。

## 剑桥撑篙适合带孩子的家庭吗?

**适合。专人撑篙船非常适合家庭出行,儿童在成人陪同下也可参加。拼船和私人游览所用的船只都又宽又平、非常稳固,向导会负责全部撑篙和讲解工作,而且没有固定的最低年龄限制,所以即便是婴儿和幼儿也可以同行。对家庭来说,私人撑篙船通常是最省心的选择,因为那是属于你们自己的船,节奏也由你们掌控。**

<img src="/images/uploaded/blog/punting-with-kids-cambridge-s1.avif" alt="剑桥康河上,拼船撑篙船上乘客撑着遮阳伞" width="1080" height="810" loading="lazy">

家长最担心的那件事,晃动,恰恰是坐下之后最不容易让人惊讶的部分。这些不是竞速用的船。专人撑篙船宽大而平稳,你坐得又低又靠中间,整趟行程更像是缓缓漂流,而不是刺激的乘船体验。几分钟内,大多数孩子就会放松下来,开始指着桥梁和鸭子。

让这一切对家庭友好的关键在于,你不用负责掌控这艘船。有受过训练的人在为你撑篙、讲解,你可以专心看着孩子,而不用忙着和长篙较劲。这也是为什么我通常会建议大多数家庭选择[私人游览](/zh/tours/private-cambridge-punting-tour/):带着小孩子的话,拥有专属的船只,再加上一位只服务你们的向导,能让整件事都不那么让人紧张。

## 撑篙的最低年龄限制是多少?

**主要的专人撑篙行程没有设定固定的最低年龄。运营商欢迎婴儿和幼儿同行,普遍适用的一条规则是:16岁及以下的儿童必须由成人陪同,并且要求儿童在水上保持坐好、有人看管。所以年龄问题,本质上其实是一个监护问题。**

<img src="/images/uploaded/blog/punting-with-kids-cambridge-s2.avif" alt="船夫在剑桥康河上撑篙一艘拼船" width="1080" height="810" loading="lazy">

这一点常常让期待像游乐设施那样有明确年龄限制的家长感到意外。通常并没有这样的硬性规定。在一趟平稳的专人撑篙行程中,船夫会很乐意接受怀抱中的婴儿。他们真正在意的是,每个孩子身边都有一位负责任的成人,并且在船只行驶时保持原位,这在水上本就是常识。

规则会因公司而异,所以预订时值得快速确认一下。如果你正在权衡各家运营商,我们的[对比页面](/zh/compare/)把它们一次列出来,[价格指南](/zh/guides/cambridge-punting-prices/)也说明了不少行程是否为儿童提供优惠票价。

| 需要了解的信息 | 通常的答案 |
|---|---|
| 最低年龄 | 专人撑篙行程没有设定 |
| 婴儿和幼儿 | 欢迎同行,通常按怀抱婴儿计算 |
| 是否需要成人陪同 | 需要,适用于16岁及以下的任何儿童 |
| 水上行为要求 | 儿童须保持坐好并有人看管 |
| 船只容量 | 拼船家庭船只最多可容纳约12人 |
| 救生衣 | 可按需提供儿童尺寸,请提前咨询 |
| 婴儿车 | 通常可在登记处自行承担风险寄存 |

*不同运营商的规定各有差异,请与你选定的公司确认具体细节。*

## 安全吗?有没有儿童救生衣?

**专人撑篙船的设计本身就宽大稳固,不易倾覆,而且全程都由训练有素的向导掌控,这正是让一次家庭出行保持从容的关键。船上并非默认标配儿童尺寸的救生衣,但运营商可按需提供儿童和成人不同尺寸,通常需要提前至少24小时通知。如果你想要救生衣,请在预订时提出,而不是等到当天。**

<img src="/images/uploaded/blog/punting-with-kids-cambridge-s3.avif" alt="康河上的国王学院礼拜堂与一只鸭子,剑桥" width="1080" height="810" loading="lazy">

我不会为你编造一个安全统计数字,因为真实的情况其实比任何数字都简单:流经The Backs的这段河道水流缓慢,部分河段水位较浅,你坐在一艘又宽又稳的船上,由有经验的人在为你撑篙。家长能做的主要是那些常识性的事:让小孩子保持坐好、扶稳幼儿,如果这能让你更安心,可以提前申请一件救生衣。

提前24小时通知这一点很关键。因为并非每艘船都常备儿童尺寸,当天临时申请很可能落空,你也不希望在踏上台阶时才发现这一点。预订时发一条简短消息就能解决这个问题。想了解行程本身实际是什么样子,我们关于[第一次撑篙会经历什么](/zh/blog/what-to-expect-first-time-punting-cambridge/)的指南逐步做了介绍。

## 家庭应该选哪条撑篙行程?

**对大多数家庭来说,私人撑篙船是最轻松、压力最小的选择,因为你能拥有专属的船只,自己掌控节奏,而且向导只专注于你的团队,这在带着好动的孩子时格外重要。拼船专人撑篙游览价格更实惠、更热闹,适合有年纪较大、性情较沉稳孩子的家庭,他们能安心地和陌生人共处45分钟。**

<img src="/images/uploaded/blog/punting-with-kids-cambridge-s4.avif" alt="船夫为康河上的乘客撑篙,剑桥" width="1080" height="810" loading="lazy">

这两种选择的区分通常取决于孩子的年龄和性情,而不是预算。幼儿和年龄很小的孩子更适合私人游览,因为他们哪怕闹一次小情绪或困了,也只是你们自己团队的事,而且你可以随时请向导调整安排。年龄稍大、能安静坐着看风景的孩子,在拼船行程中也完全没问题,而且拼船能帮你省下不少费用。

| | 拼船专人撑篙游览 | 私人撑篙船 |
|---|---|---|
| 谁和你共乘一船 | 你和其他游客 | 只有你的家人 |
| 节奏与停留 | 由整船共同决定 | 由你和向导共同商定 |
| 最适合 | 年龄较大、性情沉稳的孩子 | 幼儿、混合年龄段、大家庭 |
| 费用 | 按人头计价,人均更实惠 | 按整船计价,全家出行最划算 |
| 带小小孩的压力 | 较高;要与他人共享空间 | 较低;向导专属于你 |

*可在[价格指南](/zh/guides/cambridge-punting-prices/)查看实时数字和儿童票价;价格会随季节变化。*

## 带幼儿和婴儿车出行有什么建议?

**有,几条能省下不少麻烦的建议。出发前先安排好婴儿车,因为大多数运营商允许你在登记处自行承担风险寄存,而不是带上船。带好防晒用品和零食,把行程安排在午睡时间前后,让幼儿坐在船中间最稳的位置。带着一岁以下的婴儿时,通常会按"怀抱婴儿"计算,而不占用一个付费座位。**

<img src="/images/uploaded/blog/punting-with-kids-cambridge-s5.avif" alt="康河垂柳夹岸的水域中的鹅群,剑桥" width="1080" height="810" loading="lazy">

婴儿车是很多家庭容易忘记的一环。你没办法把婴儿车推上撑篙船,所以提前知道可以在登记处寄存,能避免在河边临时手忙脚乱。除此之外,任何一次带小孩出门都适用的常识,在这里同样适用:零食、遮阳帽,以及挑一个没人特别疲惫的时段出行。

以下是我通常根据孩子年龄给家庭提出的建议。

| 儿童年龄 | 最适合的方式 | 需要注意的地方 |
|---|---|---|
| 婴儿(1岁以下) | 私人撑篙船,通常按怀抱婴儿计算,不计入人头 | 阳光和遮阳;记得带帽子和遮罩 |
| 幼儿(1到4岁) | 私人撑篙船;让他们坐好并靠近船中间 | 好动;扶稳并配合午睡时间安排 |
| 稍大的孩子(5到9岁) | 拼船或私人皆可;他们会很喜欢寻找桥梁 | 长时间等待容易无聊;建议提前预订避开排队 |
| 年龄更大的孩子(10岁以上) | 拼船专人撑篙游览完全没问题,而且更实惠 | 无需过多担心;他们通常也很喜欢听故事 |

*基于带领家庭在康河上的实际经验给出的一般性建议;每个孩子的情况都不同。*

如果撑篙只是一次家庭出游的一站,我们整理的[剑桥好玩的事](/zh/blog/things-to-do-in-cambridge/)能帮你合理安排,而不用疲于奔波,如果你想比较各家运营商,剑桥旅游局的[Visit Cambridge](https://www.visitcambridge.org/place-categories/punting/)也维护着一份实时的运营商清单。出发前,也值得看看剑桥市议会提供的[撑篙安全与运营商信息](https://www.cambridge.gov.uk/punting)。

## 那么,带孩子撑篙值得吗?

**对大多数家庭来说,答案是肯定的。船只稳固,节奏轻柔,向导负责最辛苦的部分,而且没有年龄门槛把年幼的孩子挡在河面之外。如果孩子年纪较小就选私人撑篙船,如果想要救生衣请提前申请,把婴儿车安排在登记处寄存,你就能拥有剑桥之行中最平静、最难忘的半小时之一。**

<img src="/images/uploaded/blog/punting-with-kids-cambridge-s6.avif" alt="一艘木质撑篙船行驶在康河一段绿树成荫、垂柳夹岸的水域,剑桥" width="1080" height="810" loading="lazy">

最能享受这趟行程的家庭,往往是提前规划好这些细节的人:根据孩子的年龄选对行程,挑一个合适的时段,并提前和运营商简单确认救生衣和票价。做对这几点,这条河会为孩子展现一个他们真正会记住的剑桥,鸭子、桥梁,一样都不少。
